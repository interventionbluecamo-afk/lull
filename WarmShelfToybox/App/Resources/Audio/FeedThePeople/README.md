# Feed The People Audio

Feeding and character response sounds.

Needed:

- `food-pickup`
- `food-release`
- `food-plop`
- `feed-receive`
- `feed-happy`
- `soft-mmm`
- `soft-exhale`
- `feed-chew-soft-1`
- `feed-chew-crunch-1`
- optional gentle decline sound

Design target: warm, tiny, non-verbal. Avoid spoken words and reward phrases.

Chew sounds should be occasional, quiet, and never played for every feeding. They should read as tactile confirmation, not a joke.
