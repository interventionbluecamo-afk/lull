# Puddle Play Audio

Water and creature sounds for Puddle Play.

Needed:

- `puddle-tap-1`
- `puddle-ripple-1`
- `puddle-raindrop-1`
- `puddle-creature-1`

Design target: soft water close to the hand. The first splash can have a little body; repeat taps should stay quiet enough that a parent would not mute the app.
