# Audio

Short, soft sound effects for Warm Shelf toys.

## Current

- `bubble-pop.mp3`: current shared bubble pop source.

## Expected Names

AudioManager already looks for these names and falls back safely when files are missing:

- Bubbles: `bubble-pop-small-1`, `bubble-pop-medium-1`, `bubble-pop-large-1`, `bubble-pop-rare-1`
- Shared taps: `empty-tap`, `soft-ripple`, `soft-tap`, `felt-tap`
- Clay Blocks: `block-pickup`, `block-release`, `block-settle`, `mystery-shape`
- Shelf: `shelf-transition`, `soft-whoosh`
- Feed: `food-pickup`, `food-release`, `food-plop`, `feed-receive`, `soft-mmm`, `feed-happy`, `soft-exhale`, `happy-hum`, `feed-decline`, `feed-chew-soft-1`, `feed-chew-crunch-1`
- Puddle: `puddle-tap-1`, `puddle-ripple-1`, `puddle-raindrop-1`, `puddle-creature-1`

Use `.mp3`, `.wav`, or `.m4a`. Keep files short and quiet, with most clips below 700ms, peaks below -3 dB, and no sharp transient clicks.
