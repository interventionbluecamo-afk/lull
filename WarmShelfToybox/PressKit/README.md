# Lull press kit + NotebookLM pack

Prepared November 13, 2026. **Start with [the product overview](NotebookLM/01-Lull-Overview.txt)** for NotebookLM; it is self-contained. Open [index.html](index.html) for a browsable visual catalog.

## Contents

- **NotebookLM/**: factual overview, a draft 5–6-minute two-host podcast, reusable prompts for audio/video/carousels/FAQ/slides, and quick-start instructions.
- **Copy/**: short/long descriptions, fact sheet, founder story outline, social captions, a 30-second explainer and future real-media shot list.
- **Assets/**: existing icon, hero, nine toy cutouts, marketing cards, actual dated development captures and separately labeled historical store composites. Originals are unchanged.
- **Asset-Catalog.csv / .json**: file-by-file captions, dimensions, source paths, hashes, provenance and version/use labels.
- **Asset-Guide.md**: recommended visuals and how to use each group.
- **Internal/**: repository-only maintenance/evidence notes and full game asset index. Excluded from the public press ZIP.

The artwork includes AI-assisted promotional illustrations. These are labeled separately from real app screenshots. The kit contains no private review receipts, purchase/account screens, child photos, cancelled search-header art or Ladybug Kraft prototype assets. Public availability is not freshly verified, so the reusable copy makes no launch announcement.

## Quick podcast workflow

1. Upload `NotebookLM/01-Lull-Overview.txt` into a new notebook.
2. Add `02-Podcast-Script.txt` if you want the proposed conversation as a structural guide.
3. Choose Audio Overview in Studio, paste the podcast prompt from `Prompts.txt`, generate and listen before publishing. The tool may paraphrase the script.

Google's [source guide](https://support.google.com/gemininotebook/answer/16215270?hl=en) supports text/Markdown uploads, and its [Audio Overview guide](https://support.google.com/gemininotebook/answer/16212820?hl=en) describes format and prompt customization. The included START-HERE file has the full instructions. No NotebookLM content has been uploaded or generated on your account by this task.

## Export again

From `WarmShelfToybox/`, run `python3 Tools/Marketing/package_press_kit.py`. This verifies original asset hashes, rebuilds the visual index, creates separate Press Kit and NotebookLM ZIPs on the Desktop, and checks archive integrity. Copy-only changes do not require an app build.
