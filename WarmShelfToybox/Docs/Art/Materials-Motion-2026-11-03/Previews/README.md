## Capture setup

The DEBUG-only `LULL_DEBUG_FULL=1` and `LULL_DEBUG_TOY` launch flags select each toy. Meadow uses `LULL_DEBUG_MEADOW_NIGHT=0/1`, Mix-Up uses `LULL_DEBUG_MIXUP_INDEX=0`, Window uses `LULL_DEBUG_PHASE=0.35`, and Drop Dots uses `LULL_DEBUG_DROPDOTS_DEMO=1`. These flags do not modify the Release purchase flow.

Simulator captures used one booted simulator at a time. Launch/boot screens were replaced with rendered scenes before acceptance; no image-generation or image-editing process was used on these screenshots.
